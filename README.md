# .github

Organization profile and shared community defaults for [Datagram Messenger](https://github.com/datagram-messenger).
This repository maintains the GitHub front door, not the messenger implementation.

- [profile/README.md](profile/README.md) — public organization profile
- [profile/assets/datagram-hero.svg](profile/assets/datagram-hero.svg) — monochrome profile banner
- [CONTRIBUTING.md](CONTRIBUTING.md) — shared contribution guide
- [ISSUE_TEMPLATE/](ISSUE_TEMPLATE/) — default issue forms and configuration
- [pull_request_template.md](pull_request_template.md) — default pull request template

GitHub displays `profile/README.md` on the organization overview; this README is for repository maintenance.
Community files are inherited fallbacks, not copies. Project-specific files take precedence.
A repository with its own valid issue templates or configuration uses none of the shared issue-template set.

Keep profile copy brief, claims verifiable and profile URLs absolute. Preserve the banner's accessible text.
Before publishing, check linked paths, SVG XML and `git diff --check`; preview the profile on GitHub.
