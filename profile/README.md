Datagram is built from the transport layer up. At its core is **[DGProto v1](https://github.com/datagram-messenger/dgproto-go)** — a custom binary wire protocol with mutual authentication, end-to-end encryption, replay protection, and forward secrecy. Not bolted on. Built in.
