At its core is **[DGProto v1](https://github.com/datagram-messenger/dgproto-go)** — a draft binary protocol for encrypted client–server communication over TCP. Noise XX, ChaCha20-Poly1305, replay protection, and directional rekeying. Built in, not bolted on.
