An open-source project building Datagram Messenger on DGProto.
DGProto v1 is a draft protocol for encrypted client–server transport over TCP.

- [server](https://github.com/datagram-messenger/server) — Go application server toolkit
- [dgproto-go](https://github.com/datagram-messenger/dgproto-go) — Go wire and session library
- [dgproto-rs](https://github.com/datagram-messenger/dgproto-rs) — Rust/Tokio client
- [dgproto-wireshark](https://github.com/datagram-messenger/dgproto-wireshark) — Lua Wireshark dissector
